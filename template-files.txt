# Which template files projects keep in sync. Read by scripts/sync-template.sh.
#
# [owned]   The template owns these. A sync replaces them (with the project's modules
#           applied), and deletes them when the template drops them. Projects do not
#           edit them; change the template instead. AGENTS.md is the exception: the
#           "Project-specific rules" section at its end belongs to the project and is kept.
# [seeded]  Copied once by the template, then owned by the project. A sync never touches
#           them; it writes the template's changes to them as a patch to review.
